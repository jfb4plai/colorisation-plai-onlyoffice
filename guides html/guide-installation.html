Guide d'installation — Colorisation PLAI pour OnlyOffice

PLAI

Prérequis

  • Windows 10 ou 11
  • Connexion internet au moment de l'installation, puis à chaque fois que possible ensuite — le plugin charge son contenu en ligne et se met à jour tout seul ; il reste utilisable hors ligne une fois qu'il a pu se charger au moins une fois
1
Télécharger OnlyOffice Desktop Editors

OnlyOffice est une suite bureautique gratuite, open source et européenne, compatible avec les fichiers .docx, .xlsx et .pptx.

https://www.onlyoffice.com/fr/download-desktop.aspx
  1. Télécharger l'installeur Windows (.exe)
  2. Lancer l'installeur et suivre l'assistant d'installation
  3. Une fois installé, ouvrir OnlyOffice pour vérifier qu'il fonctionne
2
Récupérer le fichier du plugin

Le plugin est fourni par l'équipe PLAI sous la forme d'un seul fichier :

colorisation-plai.plugin
  1. Récupérez ce fichier auprès de l'équipe PLAI (email, partage réseau, clé USB…)
  2. Enregistrez-le n'importe où sur votre ordinateur (le Bureau ou vos Téléchargements conviennent) — il ne doit pas être décompressé
Code source : pour information, le code du plugin est public sur github.com/jfb4plai/colorisation-plai-onlyoffice — mais ce dépôt ne sert qu'à l'hébergement technique, pas à télécharger le plugin : utilisez toujours le fichier fourni par l'équipe PLAI.
3
Installer le plugin dans OnlyOffice
  1. Ouvrir OnlyOffice Desktop Editors et ouvrir n'importe quel document Word (.docx)
  2. Cliquer sur l'onglet Modules complémentaires dans le ruban
  3. Cliquer sur Gestionnaire de Plugins
  4. Cliquer sur le lien Installer le plugin manuellement (en haut à droite de la fenêtre)
  5. Dans la boîte de dialogue, sélectionner le fichier colorisation-plai.plugin récupéré à l'étape précédente, puis cliquer sur Ouvrir
Une seule fois : cette installation ne se fait qu'une fois par ordinateur. Les mises à jour du plugin arrivent ensuite automatiquement — voir l'étape 5.
4
Vérifier l'installation
  1. Dans l'onglet Modules complémentaires, l'icône Colorisation PLAI doit apparaître dans le ruban (sur un document Word)
  2. Cliquer dessus : le panneau de colorisation s'ouvre dans une fenêtre
  3. Tester rapidement : bouton Coloriser les phonèmes sur un texte contenant quelques mots
Important : ce premier chargement du panneau se fait en ligne — restez connecté à internet lors de ce premier essai. Une fois qu'il s'est chargé au moins une fois avec succès, il reste utilisable hors connexion.
5
Mises à jour automatiques

Le plugin se met à jour tout seul, en arrière-plan, sans rien réinstaller :

  • Quand l'ordinateur est connecté à internet, chaque ouverture du panneau vérifie discrètement s'il existe une version plus récente
  • Si oui, elle est téléchargée en tâche de fond et prendra effet à la prochaine ouverture du panneau — jamais en interrompant un travail en cours
  • Sans connexion, le plugin continue de fonctionner normalement avec la dernière version déjà enregistrée sur l'ordinateur
En clair : une fois cette installation faite, vous n'aurez normalement plus jamais besoin de refaire ces étapes — sauf annonce contraire de l'équipe PLAI (changement majeur, nouvel ordinateur…).

En cas de problème

"Installer le plugin manuellement" n'apparaît pas dans le Gestionnaire de Plugins ?
Vérifier la version d'OnlyOffice Desktop Editors (Aide → À propos) : une version trop ancienne peut ne pas proposer cette option. Mettre à jour OnlyOffice.
Le panneau reste vide ou affiche une erreur au premier lancement ?
Vérifier la connexion internet : le tout premier chargement doit se faire en ligne. Réessayer une fois connecté.
L'icône Colorisation PLAI n'apparaît que sur certains documents ?
C'est normal : le plugin ne s'active que sur les documents Word (.docx), pas sur les classeurs Excel ni les présentations.
Une mise à jour semble ne jamais arriver ?
Le plugin ne se met à jour qu'à l'ouverture du panneau, avec une connexion internet active à ce moment-là. Rouvrir le panneau une fois connecté.
