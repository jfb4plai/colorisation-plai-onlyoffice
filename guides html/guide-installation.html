Guide d'installation — Colorisation PLAI pour OnlyOffice

PLAI

Prérequis

  • Windows 10 ou 11
  • Connexion internet (uniquement pour le téléchargement initial)
1
Télécharger OnlyOffice Desktop Editors

OnlyOffice est une suite bureautique gratuite, open source et européenne, compatible avec les fichiers .docx, .xlsx et .pptx.

https://www.onlyoffice.com/fr/download-desktop.aspx
  1. Télécharger l'installeur Windows (.exe)
  2. Lancer l'installeur et suivre l'assistant d'installation
  3. Une fois installé, ouvrir OnlyOffice pour vérifier qu'il fonctionne
2
Télécharger le plugin Colorisation PLAI
https://github.com/jfb4plai/colorisation-plai-onlyoffice/releases
  1. Cliquer sur le lien ci-dessus et télécharger le fichier .zip de la dernière version
  2. Extraire le ZIP : clic droit sur le fichier → Extraire tout
3
Installer le plugin
Méthode A — recommandée

Copie manuelle dans le dossier plugins

  1. Ouvrir l'Explorateur de fichiers
  2. Dans la barre d'adresse, taper :
    %LOCALAPPDATA%
    puis valider avec Entrée
  3. Naviguer vers :
    ONLYOFFICE\DesktopEditors\data\sdkjs-plugins\
  4. Copier le dossier extrait dans ce répertoire et le renommer en :
    {C0L0R1Z4-PL41-0000-0000-000000000001}
  5. Vérifier que config.json se trouve directement dans ce dossier
Astuce : le dossier AppData est caché par défaut. Le raccourci %LOCALAPPDATA% permet d'y accéder directement.
Méthode B — alternative

Via le gestionnaire de plugins

  1. Ouvrir OnlyOffice Desktop Editors
  2. Cliquer sur l'onglet Modules complémentaires
  3. Cliquer sur Gestionnaire de Plugins
  4. Cliquer sur Installer depuis un fichier
  5. Sélectionner le fichier config.json du plugin extrait
Note : cette méthode peut ne pas être disponible sur toutes les versions d'OnlyOffice.
4
Vérifier l'installation
  1. Fermer complètement OnlyOffice, puis le relancer
  2. Ouvrir un document texte (.docx)
  3. Cliquer sur l'onglet Modules complémentaires
  4. L'icône Colorisation PLAI doit apparaître dans la barre
  5. Cliquer dessus : le panneau de colorisation s'ouvre sur la droite

En cas de problème

Le plugin n'apparaît pas ?
Vérifier que le dossier du plugin contient bien config.json au premier niveau (pas dans un sous-dossier).
Erreur au chargement du plugin ?
Ouvrir la console développeur avec Ctrl + Shift + F12 pour identifier l'erreur.
Le dossier sdkjs-plugins est introuvable ?
Vérifier qu'OnlyOffice a été lancé au moins une fois. Le dossier est créé au premier démarrage.
